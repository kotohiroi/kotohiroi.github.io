プライバシーポリシー

KOTOSAKI ToDrive（以下「本アプリ」）

制定日: 2026年10月25日

1. 収集する情報

本アプリは、開発者が管理するサーバーへ、あなたのファイル、個人情報、利用状況を送信・収集しません。広告や利用状況の解析も行いません。

2. 端末の中だけに保存する情報

転送を正しく続けるため、次の情報を端末内のアプリ専用領域にだけ保存します。

  • 転送の記録（ファイル名、大きさ、更新日時、内容のハッシュ値、Google ドライブ上のファイル ID、アップロードを途中から再開するための一時 URL）
  • 認可した Google アカウントのメールアドレスと、そのアカウントを識別するための Google の識別子
  • あなたが選んだ設定（移動元フォルダ、保存先、実行条件など）

これらの情報は、端末のバックアップや機種変更時のデータ移行の対象外にしています。

3. Google ドライブの利用

本アプリは、Google ドライブの https://www.googleapis.com/auth/drive.file 権限だけを使います。この権限で扱えるのは、本アプリが作成したファイルとフォルダだけです。

本アプリは、あなたが選んだ端末のフォルダにあるファイルを、あなた自身の Google ドライブへコピーするためにだけこの権限を使います。ドライブ上のファイルの削除、共有、権限の変更は行いません。

4. Google の認証情報

Google アカウントの認可は、Google Play 開発者サービスが管理します。本アプリは、通信のための一時的なアクセストークンをメモリ上でだけ使い、保存しません。

5. Google API から受け取る情報の扱い

本アプリが Google API から受け取った情報の使用および他のアプリへの移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

ToDrive's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 更新の確認

新しいバージョンがあるかを確かめるため、本アプリは公開されているリリース情報の一覧（Supabase 上）を読み取ります。このとき、あなたに関する情報は送りません。ただし通信の性質上、接続先には端末の IP アドレスが届きます。

7. 第三者への提供

本アプリは、あなたの情報を第三者に提供、販売、共有しません。

8. データの削除とアクセスの取り消し

  • 本アプリをアンインストールすると、端末内に保存した情報はすべて削除されます。
  • Google ドライブへコピーしたファイルは、あなた自身のファイルとしてドライブに残ります。不要であれば、ドライブから削除してください。
  • 本アプリの Google ドライブへのアクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

9. 改定

このポリシーを変更する場合は、このページを更新し、制定日・改定日を記載します。
